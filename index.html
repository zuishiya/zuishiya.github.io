新手教程

怎么用

基本流程

  • 把地图图片拖进窗口，或点「导入底图」；会自动适配视野，并把网格从图片左上角起算、整格铺满图片（边缘落在格线上）。想改格距就手动调「每米像素」，或点「按图片对齐格子」重来
  • 点工具栏「棋子」再点地图放置；双击空白处也能快速加
  • 棋子列表里点一行选中，点 ◎ 把镜头移过去，双击行也一样；× 删除，选中后还能「复制」同款
  • 选择工具下直接拖动棋子；按住 Alt 拖动可临时不吸附网格
  • 选中棋子后在右侧上传头像，或把图片直接拖到棋子上
  • 对齐地图格子：把「格子像素」调成地图一格的像素（或用 −/＋ 微调、或「按图片对齐」），点「拖动网格对齐」在地图上拖，网格线跟着走；方向键微调 1px（Shift 10px），Shift+滚轮改格距
  • 对齐后改「每格 × 米」只改比例，格子大小不变；测距、范围、棋子体型的米数都按新比例算
  • 网格太抢眼就拉「浓淡」滑杆
  • 选圆形 / 扇形工具后在地图上拖拽；直接单击则用面板里设定的半径；按下处吸附圆心、松手处吸附棋子，从甲拖到乙半径 / 射程就是两棋子间距
  • 半径、张角都是自由输入，没有固定档位：半径 0.5–5000 米、张角 1–360°；拖拽时以松手距离/方向为准，面板数值用于单击放置
  • 其它可自定义上限：视野 0.5–1000 米、揭雾笔刷 0.5–200 米、墙厚 0.05–20 米、棋子体型 0.1–100 格、移动步长 0.1–9999 米；超出会在失焦时自动收回到上限
  • 选中棋子后可直接按方向键按「步长」移动；地图旋转后方向键仍按屏幕方向走（上就是屏幕上）
  • 选中棋子后点「以选中棋子为圆心画圆」＝ 20 米射击圈；再点圆形工具在圈内点一下就是 5 米 AOE
  • 「测距」拖拽时起点、终点落在棋子上会自动对齐棋子圆心，量棋子到棋子的距离很方便
  • 选中一个范围，面板会列出范围内的棋子（橙色虚线圈高亮，按棋子中心判定）；刚画完也会提示命中了谁
  • Ctrl+Z 撤销 · Ctrl+Shift+Z 重做（增删棋子、移动、画范围、先攻调整都能回退）
  • 选中棋子后可以直接改「坐标」两个数字，或用「步长」+ 九宫格方向键一格一格挪；拖动完坐标框也会同步
  • 先攻：「＋ 加入」把选中棋子加进列表（没选中就加空白角色），改先攻值自动排序；「下一回合」高亮下一位，轮完自动进下一回合；点行选中棋子，双击连镜头一起过去
  • 摆件（木桶/木箱/圆桌/椅子/火把/树/石像/地毯）纯装饰；墙用工具栏「墙 (W)」拖拽画，会挡住棋子移动和范围视线
  • 右键/长按摆件或墙体可选中、复制、删除；选中后按住拖动可移动
  • 墙有厚度：面板「场景」里的「墙厚」可改；选中一面墙改的是这一面，没选中时改的是下一面新墙。范围遇到墙会被切断，命中与视野都按墙的实际厚度算
  • 迷雾：面板「迷雾」里启用；默认每个棋子都提供视野（可在棋子编辑里取消，怪物就不会照亮四周），墙会挡住视野；「手动揭雾」拖动涂抹，揭开的区域随存档保存
  • 面板上每块标题（地图 / 棋子 / 先攻 / 范围 / 场景 / 存档）都能点一下收起，收起状态会记住
  • 右键单击画布出菜单（手机上长按）：空白处可加棋子 / 导入底图 / 截图，棋子上可复制 / 加先攻 / 换头像 / 删除，范围上可删除
  • 选中范围后拖动内部即可整体移动。磁铁开启时，圆心、扇形顶点或按下处较近的线端会吸附到棋子或格心；半径、方向和线长不变。关闭磁铁或按住 Alt 可自由拖动。
  • 棋子「体型」可以直接填 0.5–10 格，不再只有 1/1.5/2/3
  • 顶部磁铁按钮＝捕捉开关：开启时棋子移动、测距/圆/扇形两端都会吸附格子中心（靠近棋子吸棋子），关闭则完全自由；旋转后九宫格方向仍按屏幕方向走
  • 网格：先用「格子像素」对准地图一格，再点「拖动网格对齐」拖到位（偏移 X/Y 可微调）
  • 地图区「存为预设」把当前底图 + 网格存成按钮，以后像地牢 / 洞穴那样一点就切；长按或右键自定义预设可删
  • 存档区「截图复制」把当前画面复制到剪贴板；浏览器不允许时自动下载 PNG
  • 右上角「教程」可以随时重看 6 步新手引导；第一次打开会自动出现，跳过后不再自动弹

键鼠

  • 地图旋转：地图区「⟲ / ⟳」每次转 90°，或在角度框里输（正数顺时针）；旋转后自动适配视野，棋子、范围、网格一起转，文字保持水平
  • 滚轮 缩放 · 空格 / 中键 拖地图；右键单击出菜单、按住右键拖动仍可平移
  • 手机上：单指拖地图 / 拖棋子，双指捏合缩放；点右上「☰」开面板
  • V 选择 · T 棋子 · C 圆 · F 扇形 · M 测距 · G 网格
  • Delete 删除选中 · Esc 取消 / 回到选择
